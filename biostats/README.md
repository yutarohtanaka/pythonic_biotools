# `biostats`: Survival, Competing Risks, Robust Regression & High-Dimensional Correlation

Standalone Python implementations of Efron-tie Cox Proportional Hazards (`fit_cox_ph_efron`), Fine–Gray IPCW competing-risks regression (`fit_fine_gray_ipcw`, port of R `cmprsk`), MacKinnon–White HC3 heteroskedasticity-consistent WLS (`fit_wls_hc3`), and vectorized genome-wide Pearson/Spearman correlation scans with pooled-null permutation empirical FDR (`permutation_empirical_fdr`).
