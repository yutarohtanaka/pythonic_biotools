# `decoupler-ulm`: Univariate Linear Model Gene-Program Projection

Standalone Python implementation of Univariate Linear Model (`ulm_tstat`, following Badia-i-Mompel et al., *Bioinformatics Advances* 2022), `log2_dot`, and `top_k_zscore` gene-expression program projection from continuous NMF/cNMF factor weights onto bulk or pseudobulk matrices.
