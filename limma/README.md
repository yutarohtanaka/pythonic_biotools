# `limma`: Python Implementation of `limma::eBayes`

Standalone Python implementation of the Bioconductor **`limma`** empirical Bayes variance moderation framework (Smyth, *Stat Appl Genet Mol Biol* 2004; Phipson et al., 2016), including exact Newton-Raphson `trigamma_inverse`, `fit_f_dist`, `squeeze_var`, `moderated_ttest`, `moderated_lm_contrast`, and `limma_top_table`.
