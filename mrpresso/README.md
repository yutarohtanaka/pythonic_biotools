# `mrpresso`

Vectorized Python implementation of **MR-PRESSO** (*Mendelian Randomization Pleiotropy RESidual Sum and Outlier*) and **Multivariable MR-PRESSO** for detecting and correcting horizontal pleiotropy in summary-level Mendelian randomization, with exact upstream R parity mode.

## Citation

> Verbanck, M., Chen, C.-Y., Neale, B., & Do, R. (2018). Detection of widespread horizontal pleiotropy in causal relationships inferred from Mendelian randomization between complex traits and diseases. *Nature Genetics*, 50(5), 693–698. https://doi.org/10.1038/s41588-018-0099-7

## Statistical Model

Given $J$ independent genetic instruments with exposure summary statistics $(\hat{\beta}_{X,j}, s_{X,j})$ (shape $(J,)$ or $(J, P)$ for $P \ge 2$ exposures), outcome summary statistics $(\hat{\beta}_{Y,j}, s_{Y,j})$, and inverse-variance weights $w_j = s_{Y,j}^{-2}$:

1. **Leave-One-Out Observed RSS (`leave_one_out_ivw`)**:
   Each leave-one-out IVW slope $\hat{\beta}^{(-j)}$ is evaluated analytically via rank-1 updates (exact $O(J)$ sums for $P = 1$; Sherman-Morrison downdates $(X^\top W X - w_j x_j x_j^\top)^{-1}$ and hat-matrix leverage $r_j = e_j / (1 - h_j)$ for $P \ge 2$):
   $$\text{RSS}_{\text{obs}} = \sum_{j=1}^J \omega_j \left(\hat{\beta}_{Y,j} - x_j^\top \hat{\beta}^{(-j)}\right)^2,$$
   where $\omega_j = 1$ (`weighted_rss=False`) or $\omega_j = s_{Y,j}^{-2}$ (`weighted_rss=True`).

2. **Global Test**:
   Simulates $K$ (`nb_distribution`) Monte Carlo null datasets under zero horizontal pleiotropy:
   $$\beta_{X,j}^{(k)} \sim \mathcal{N}(\hat{\beta}_{X,j}, s_{X,j}^2), \qquad \beta_{Y,j}^{(k)} \sim \mathcal{N}(x_j^\top \hat{\beta}^{(-j)}, s_{Y,j}^2),$$
   comparing $\text{RSS}_{\text{obs}}$ against the empirical distribution $\{\text{RSS}_{\text{exp}}^{(k)}\}_{k=1}^K$.

3. **Outlier Test & Outlier-Corrected IVW**:
   When $p_{\text{global}} < \alpha$ (`signif_threshold`), per-instrument $p$-values compare observed LOO squared residuals against their simulated null distribution, apply Bonferroni correction $\min(1, J \cdot p_j)$, exclude significant outliers, and re-fit no-intercept IVW on the retained instruments.

4. **Distortion Test**:
   Quantifies the percentage bias induced by horizontal pleiotropic outliers:
   $$D = 100 \times \frac{\hat{\beta}_{\text{raw}} - \hat{\beta}_{\text{corr}}}{|\hat{\beta}_{\text{corr}}|},$$
   with a two-sided bootstrap $p$-value generated by resampling non-outlier instruments with replacement.

## Python Quickstart

```python
import numpy as np
from mrpresso import mr_presso, mvmr_presso

rng = np.random.default_rng(42)
bx = rng.uniform(0.05, 0.25, size=30)
sx = np.full(30, 0.01)
sy = np.full(30, 0.02)
by = 0.5 * bx + rng.normal(0.0, sy)
by[0] += 0.40  # horizontal pleiotropy outlier

# 1. Default Pythonic mode (Phipson-Smyth Monte Carlo p-values, re-fitted LOO outlier null)
res = mr_presso(by, bx, sy, sx, seed=42, settings="default")
print(res.summary())

# 2. Upstream R parity mode (matching rondolab/MR-PRESSO mr_presso.R)
res_r = mr_presso(by, bx, sy, sx, seed=42, settings="R_default")
df_main = res_r.to_dataframe()
df_snps = res_r.outlier_table()
```

## `settings="default"` vs `settings="R_default"`

| Aspect | `settings="default"` | `settings="R_default"` (`rondolab/MR-PRESSO`) |
| :--- | :--- | :--- |
| **Default `weighted_rss`** | `False` (unweighted squared LOO residuals) | `True` ($1 / s_{Y,j}^2$ precision weights matching `getRSS_LOO`) |
| **Outlier Test simulated residual** | $\beta_{Y,j}^{(k)} - x_j^{(k)\top} \hat{\beta}^{(-j),(k)}$ (re-fits simulated LOO slope per draw) | $\beta_{Y,j}^{(k)} - x_j^{(k)\top} \hat{\beta}^{(-j)}_{\text{obs}}$ (`mr_presso.R` L103–105 fixed observed LOO slope) |
| **Default `nb_distribution` ($K$)** | `5000` | `1000` (when not explicitly overridden) |
| **Empirical $p$-value estimator** | Phipson-Smyth `(count + 1) / (K + 1)` | Raw `count / K` (`sum(RSS_exp >= RSS_obs) / K`) |
| **Distortion Test bootstrap** | `(count + 1) / (K + 1)` on $\|\hat{\beta}_{\text{boot}} - \hat{\beta}_{\text{corr}}\| \ge \|\hat{\beta}_{\text{raw}} - \hat{\beta}_{\text{corr}}\|$ | Raw `count / K` on $\|\text{BiasExp}\| \ge \|\text{BiasObs}\|$ where $\text{BiasObs} = (\hat{\beta}_{\text{raw}} - \hat{\beta}_{\text{corr}}) / \|\hat{\beta}_{\text{corr}}\|$ (`mr_presso.R` L138–143) |

### Parity Notes

- In `settings="R_default"`, both `mr_presso` and `mvmr_presso` replicate `rondolab/MR-PRESSO` (`R/mr_presso.R`): `getRSS_LOO` precision weighting (`1 / se_out^2`), fixed observed leave-one-out slopes inside the per-variant Outlier Test, `NbDistribution = 1000`, raw `count / K` empirical tail probabilities, and bootstrap relative-bias distortion testing.
- Explicit user arguments (e.g., `nb_distribution=5000` or `weighted_rss=False`) override the mode defaults cleanly in both settings.

## Output Schema

- **`MRPressoResult`** (returned by `mr_presso` when $P = 1$):
  - Attributes: `n_instruments`, `snp_ids`, `exposure_name`, `beta_raw`, `se_raw`, `t_stat_raw`, `p_value_raw`, `beta_corrected`, `se_corrected`, `t_stat_corrected`, `p_value_corrected`, `rss_obs`, `rss_per_snp`, `expected_rss_per_snp`, `loo_betas`, `p_global`, `p_global_empirical`, `p_global_formatted`, `outlier_indices`, `outlier_snps`, `outlier_pvalues`, `outlier_pvalues_bonferroni`, `outlier_pvalues_chisq`, `distortion_coeff`, `p_distortion`, `nb_distribution`, `signif_threshold`, `weighted_rss`, `settings`.
  - `res.to_dataframe()`: Two-row `pd.DataFrame` (`Raw` and `Outlier-corrected`) with columns `["exposure", "mr_analysis", "causal_estimate", "sd", "t_stat", "p_value", "n_instruments", "rss_obs", "p_global", "n_outliers", "distortion_coeff", "p_distortion"]`.
  - `res.outlier_table()`: Per-SNP `pd.DataFrame` with columns `["snp", "beta_exposure", "sd_exposure", "beta_outcome", "sd_outcome", "loo_beta", "rss_obs", "rss_expected", "p_value", "p_bonferroni", "p_chisq", "is_outlier"]`.
- **`MVMRPressoResult`** (returned by `mr_presso` / `mvmr_presso` when $P \ge 2$):
  - Vectorized multi-exposure counterpart including `p_distortion_joint` alongside per-exposure `beta_raw`, `beta_corrected`, `distortion_coeff`, and `p_distortion`.
