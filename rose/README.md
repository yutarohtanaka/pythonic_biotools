# `rose`: Python Implementation of ROSE (Rank Ordering of Super-Enhancers)

Standalone Python implementation of the **ROSE** super-enhancer calling algorithm (Whyte et al., *Cell* 2013; Lovén et al., *Cell* 2013) with blacklist exclusion, promoter-window (`±2.5 kb` TSS) filtering, enhancer stitching (`12.5 kb`), geometric tangent-slope inflection thresholding, and nearest-gene annotation.
