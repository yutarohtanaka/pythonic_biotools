# `twosamplemr`: Summary-Data Mendelian Randomization & Instrument Clumping

Standalone Python implementation of classical Two-Sample and Multivariable Mendelian Randomization (`ivw_mr`, coding-invariant `mr_egger`, `weighted_median_mr`, `multivariable_mr` with Sanderson-Windmeijer conditional $F$-statistics) and palindromic-aware LD clumping (`select_mr_instruments`).
